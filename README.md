# Rentify

Aplikasi penyewaan barang berbasis web dengan sistem deposit dan pengelolaan transaksi.

## 📌 Panduan Kolaborasi GitHub

Repository ini digunakan untuk mengembangkan aplikasi Rentify secara bersama-sama oleh anggota kelompok.

### 👥 1. Clone Repository

Pertama, clone repository ke laptop masing-masing.

```bash
git clone https://github.com/Fadhilzain/Rentify.git
cd Rentify
```

### 🔄 2. Pull (Mengambil Perubahan)

Sebelum mulai coding, selalu ambil perubahan terbaru dari repository.

```bash
git pull origin main
```

### 🌿 3. Membuat Branch

Buat branch sendiri sesuai fitur yang dikerjakan.

```bash
git checkout -b fitur-nama-kalian
```

Contoh:

```bash
git checkout -b fitur-login
```

### 💻 4. Mengerjakan Fitur

Kerjakan kode sesuai tugas masing-masing anggota.

### 📦 5. Git Add

Tambahkan perubahan yang sudah dibuat.

```bash
git add .
```

### 📝 6. Git Commit

Simpan perubahan dengan pesan commit yang jelas.

```bash
git commit -m "Menambahkan fitur login"
```

### ⬆️ 7. Git Push

Kirim branch dan perubahan ke GitHub.

```bash
git push -u origin fitur-nama-kalian
```

### 🔀 8. Pull Request

Setelah melakukan push:

1. Buka repository GitHub.
2. Pilih **Compare & pull request** atau buat Pull Request.
3. Jelaskan perubahan yang telah dibuat.
4. Minta anggota kelompok melakukan review.
5. Gabungkan (merge) ke branch `main` setelah disetujui.

### ⚠️ Aturan Kolaborasi

* Selalu lakukan `git pull` sebelum mulai coding.
* Jangan langsung melakukan push ke `main` tanpa koordinasi.
* Gunakan branch masing-masing untuk mengerjakan fitur.
* Gunakan pesan commit yang jelas.
* Jangan menghapus atau mengubah kode teman tanpa koordinasi.
* Lakukan review sebelum merge ke `main`.
